إذا كنت تريد **روابط صور فقط** (وليس إنشاء صور بالذكاء الاصطناعي)، فهذه أفضل الخيارات:

## 🥇 1. Wikimedia Commons API (أفضل خيار للموسوعة)

إذا كانت مقالاتك موسوعية، فهذا أفضل مصدر.

المميزات:

* ✅ مجاني 100%.
* ✅ بدون API Key.
* ✅ ملايين الصور.
* ✅ صور مرخصة للاستخدام.
* ✅ يمكنك البحث بالعنوان.

مثال:

```text
https://commons.wikimedia.org/w/api.php?action=query&generator=search&gsrsearch=Palestine&gsrlimit=10&prop=imageinfo&iiprop=url&format=json
```

---

## 🥈 2. Wikipedia API

إذا كان المقال موجودًا في ويكيبيديا.

مثال:

```text
https://en.wikipedia.org/api/rest_v1/page/summary/Apple_Inc.
```

سيعطيك:

```json
thumbnail.source
```

وهو رابط الصورة.

---

## 🥉 3. Google Images (غير رسمي)

يمكنك البحث بالعنوان.

لكن **جوجل لا يوفر API مجاني لصور Google Images**، وأي طريقة لاستخراج الصور من Google Images تعتمد على Scraping أو خدمات خارجية، وقد تتوقف أو تتغير.

---

## 🏅 4. Unsplash API

* صور عالية الجودة.
* مجاني إلى حد معين.
* يحتاج API Key.
* مناسب للصور العامة وليس للأخبار.

---

## 🏅 5. Pixabay API

* مجاني.
* يحتاج API Key.
* مناسب للصور العامة.

---

## 🏅 6. Pexels API

* مجاني.
* يحتاج API Key.
* صور احترافية.

# إذا أردت صورًا مرتبطة بالأخبار

أنا أنصح بهذا الترتيب:

```text
Google News RSS
        ↓
رابط الخبر
        ↓
Jina AI
        ↓
النص الكامل
        ↓
Wikipedia API
        ↓
إذا وجد صورة
        ↓
استخدمها

إذا لم يجد
        ↓
Wikimedia Commons
        ↓
ابحث بالعنوان

إذا لم يجد
        ↓
احتفظ بصورة الخبر الأصلية إذا كانت متوفرة في RSS أو صفحة الخبر.
```

## إذا كان هدفك "أريد أن أكتب عنوانًا مثل"

```
ليونيل ميسي
```

ويعيد لي **20 صورة مرتبطة به من Google Images**، فهذا **لا يوجد له API مجاني ورسمي من Google**. ستحتاج إلى:

* خدمة خارجية مثل SerpAPI أو Serper (غالبًا ليست مجانية بالكامل).
* أو استخدام Scraping، وهو أقل استقرارًا وقد يخالف شروط استخدام بعض المواقع.

لذلك، إذا أردت حلًا مجانيًا ومستقرًا لموسوعة، فالأفضل الاعتماد على **Wikimedia Commons** و**Wikipedia** للصور المرخصة، واستخدام صور الخبر الأصلية عندما تكون متاحة.
